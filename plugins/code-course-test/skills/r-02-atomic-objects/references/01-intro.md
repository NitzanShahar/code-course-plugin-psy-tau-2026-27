הסבר לי באופן כללי מה הם אובייקטים בסיסיים בR.
אל תכתוב קוד. רק תסביר מהם משתנים בסיסיים. תכלול רק את הסוגים האלו
- אובייקט מספרי (numeric)
- אובייקט מחרוזת (string)
- אובייקט לוגי (logical)
- אובייקט תאריך (date)
