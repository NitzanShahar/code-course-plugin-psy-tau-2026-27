1.
הדפס את הקוד הבא, קרא לו קוד לדוגמא, והסבר בקצרה במילים מה הוא עושה

```r
x = 1
```

עצור ואל תמשיך לכתוב. חכה לתשובה שלי, בדוק שהבנתי ורק כשארשה לך המשך.

2.
הדפס את הקוד הבא, קרא לו קוד לדוגמא, והסבר בקצרה במילים מה הוא עושה

```r
x = 1
x = x + 5
x = x - 2
x = 2 * x
x = x / 3
print(x)
class(x)
```

עצור ואל תמשיך לכתוב. חכה לתשובה שלי, בדוק שהבנתי ורק כשארשה לך המשך.

3.
כתוב את הכותרת "התרגול שלך"
בקש ממני לייצר את התרגילים הבאים בסקריפט.
- יצר משתנה x שיהיה שווה ל10
- הכפל אותו ב2
- חלק ב3
- הוסף 4
- החסר 8
- הדפס לקונסולה
- בדוק איזה סוג אובייקט הוא x

עצור, ובקש ממני להדביק לך את הקוד כדי לוודא שהוא נכון. רק כשארשה לך המשך.
אם הדבקתי קוד שגוי העזר בגילוי מודרך עם טקסט ללא שימוש בקוד כדי לעזור לי להצליח. עצור וחכה שאנסה שוב.
אם הדבקתי שוב קוד שגוי העזר שוב בגילוי מודרך עם טקסט ללא שימוש בקוד כדי לעזור לי להצליח. עצור וחכה שאנסה שוב.
אם אבקש תן לי את הפתרון בקוד קצר.
