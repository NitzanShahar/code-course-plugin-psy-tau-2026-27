title: משתנה קטגוריאלי ב (contrasts)
---

1. הסבר מילולית ללא שימוש בקוד, שכאשר מכניסים משתנה פאקטוריאלי לרגרסיה, R אוטומטית ממירה אותו     למספרים לפי קידוד קבוע מראש שמוזן בתוך משתנה הפאקטור עצמו.

2. כתוב קוד בR עם שלוש שורות בלבד. שורה ראשונה מייצרת factor בשם gender, השורה השניה משתמשת בcontrast() כדי לגרום לmale להיות 0 וfemale להיות 1, השורה השלישית רק מדפיסה את הcontrast() שהגדרנו בשורה השניה.

3.  כתוב את המילים : "כעת כתוב קוד שמגדיר משתנה מגדר בקידוד דמה שבו זכר הוא +1 ונקבה היא 0". חכה שאני אכתוב את הקוד שעושה זאת. בדוק את הקוד שלי ואם טעיתי השתמש בגילוי מודרך ללא כתיבת הקוד כדי להסביר לי את הטעות שלי.

4. כתוב את המילים : "כעת כתוב קוד שמגדיר משתנה מגדר בקידוד אפקט שבו זכר הוא -1 ונקבה היא +1". חכה שאני אכתוב את הקוד שעושה זאת. בדוק את הקוד שלי ואם טעיתי השתמש בגילוי מודרך ללא כתיבת הקוד כדי להסביר לי את הטעות שלי.

5. כתוב ששלב הלימוד הסתיים

עשה את השלבים האלו אחד אחד לפי הסדר. עצור בסוף כל שלב לראות שהבנתי והצלחתי, ורק אז המשך לשלב הבא.
